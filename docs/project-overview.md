# Project Overview

## Executive Summary
This project is a Duolingo clone, a comprehensive language learning platform designed to provide an interactive and engaging learning experience. It features a robust lesson system, progress tracking, gamification elements like hearts and points, and a shop for purchasing in-game items.

## Technology Stack
| Category | Technology |
|----------|------------|
| **Framework** | Next.js (App Router) |
| **Language** | TypeScript |
| **Database** | PostgreSQL (Neon) |
| **ORM** | Drizzle ORM |
| **UI** | Tailwind CSS, Shadcn UI, Radix UI |
| **Authentication** | Clerk |
| **State Management** | Zustand |
| **Payments** | Stripe |

## Architecture
The project follows a **Monolithic** architecture, leveraging the full capabilities of the Next.js App Router for both frontend and backend logic.

## Repository Structure
- **Monolith:** Single cohesive codebase.
- **Root:** `/workspaces/typescript-node/duolingo-clone-bmad-demo`
